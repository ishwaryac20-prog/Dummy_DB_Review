# Product Dataset Analysis

A structured Excel-based project designed to analyze product information, calculate key metrics, and visualize insights using dashboards and formulas.

## Description

This project focuses on exploring a product dataset using Excel. It includes essential data analysis tasks such as calculating totals, averages, category-wise summaries, and conditional counts. Additionally, the project contains a clean and interactive dashboard that helps users understand product distribution, pricing patterns, and category insights. This repository is ideal for beginners learning Excel data analysis and dashboard creation.

## Getting Started

### Dependencies

- Microsoft Excel (2016 or later recommended)
- Windows 10 / Windows 11
- Basic understanding of Excel formulas (SUMIF, COUNTIF, AVERAGE, etc.)

### Installing

- Download or clone this repository
- Open the Excel files:
  - **Excel Assignment 1 – Data Exploration**
  - **Product Dataset Analysis Dashboard**

### Executing Program

- Open the Excel file
- Enable editing (if prompted)
- Use filters, slicers, and formulas to explore the dataset

No command required — simply open the Excel file.
